在 Chrome 侧边栏，与网页对话

ClawTab 基于当前网页内容进行 AI 问答，支持多会话与工具调用， 让你无需切换标签页就能理解、提炼、追问所看到的一切。

添加到 Chrome 在 GitHub 上查看

Chrome Web Store 上架后将替换为商店安装链接。

主要功能

为浏览网页时的思考与追问而生。

侧边栏对话

在 Chrome 侧边栏中与 AI 交流，无需离开当前页面。

网页正文抽取

基于 Mozilla Readability + NodeHtmlMarkdown 提取标题、URL 与正文，按 URL 缓存快照。

OpenAI 兼容接口

连接你自己的 OpenAI Chat Completions 兼容大模型，Base URL 与 API Key 由你掌控。

流式输出 & 思考过程

实时看到模型的回答生成，并可展开查看 reasoning 思考过程。

内置工具调用

tabSnapshotListBasic 列出标签页、tabSnapshotGet 获取网页正文，结果以 Markdown 渲染。

多会话管理

创建、切换、删除独立的对话，历史消息持久化到 IndexedDB。

如何使用

四步开始你的第一次网页问答。

  1. 1
    安装并打开侧边栏

    从 Chrome Web Store 安装 ClawTab，点击工具栏图标或使用 Chrome 侧边栏入口。

  2. 2
    填写大模型设置

    在设置面板填入 OpenAI 兼容接口的 Base URL、API Key 与 Model 名称。

  3. 3
    打开任意网页

    ClawTab 会自动抽取当前页面的标题、URL 与正文，作为对话上下文。

  4. 4
    开始提问

    在输入框中提出问题，或新建会话开始独立对话；使用 Enter 发送、Shift+Enter 换行。

数据由你掌控

ClawTab 不提供自有云端模型服务。用户输入、网页文本和聊天上下文会发送到你自行配置的大模型接口。 API Key、模型配置、会话与聊天历史以及网页快照默认保存在本地浏览器存储中 （chrome.storage.local + IndexedDB），不会上传到第三方服务。
