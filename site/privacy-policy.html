ClawTab 隐私政策

生效日期：2026-06-21

ClawTab 是一款 Chrome 扩展，用于帮助用户对当前浏览器标签页的内容进行提问。

扩展处理的数据

为提供核心功能，ClawTab 可能处理以下数据：

  • 网页内容：页面标题、URL，以及提取的文章或页面正文文本。
  • 用户输入：在 ClawTab 聊天框中输入的问题。
  • 聊天记录：此前的用户消息和助手消息。
  • 扩展设置：模型 Base URL、API Key 与模型名称。

数据用途

ClawTab 使用页面内容和用户问题，通过用户自行配置的 OpenAI 兼容 chat completion 接口生成回答。

扩展将聊天记录和模型配置保存在 Chrome 本地存储中，以便侧边栏可以恢复之前的状态。

数据共享

ClawTab 不运营自己的后端服务。

当用户发送问题时，扩展会将相关的页面内容、用户问题以及对话上下文发送到用户配置的模型接口。 该接口的隐私和数据保留策略由用户所选择的接口提供方控制。

API Key

用户输入的 API Key 保存在本地 Chrome 存储中，仅用于调用用户配置的模型接口。

远程代码

ClawTab 不会有意加载远程可执行代码。扩展包内包含其自身的 JavaScript 打包产物。

用户控制

用户可以通过扩展界面清除聊天记录。也可以通过 Chrome 扩展存储控制面板或卸载扩展的方式移除扩展数据。

联系我们

如有隐私相关问题，请通过项目 GitHub Issues 提交反馈。
