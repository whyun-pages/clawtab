ClawTab 是一個住在 Chrome 側邊欄的智慧助手。它能讀懂你目前開啟的網頁，幫你理解內容、回答問題、整理重點——就像身邊有個已經先讀過這頁的夥伴。

打開側邊欄，問一句「這篇文章在講什麼」，它就會結合眼前的網頁給你答案。你也可以請它幫忙查資料、比價格、找商品，或是同時開好幾個對話，各聊各的互不干擾。

主要功能：

- 在 Chrome 側邊欄裡就目前網頁隨時提問、聊天
- 自動讀取目前網頁的標題和內文，整理成清爽的文字後回答你的問題
- 邊產生邊顯示答案，還能看見它「思考」的過程
- 它能自己列出你開啟的分頁、讀取網頁內容，幫你完成任務
- 在背景悄悄開啟網頁並讀取內容，不會打斷你正在看的頁面
- 多站點搜尋：綜合搜尋（Google / Bing / 百度）和購物比價（淘寶 / 京東 / 閒魚 / 亞馬遜 / eBay / Best Buy）
- 回答裡提到的網頁可以直接點開，一鍵跳轉
- 多個對話隨意建立、切換、刪除，互不影響
- 答案支援 Markdown 排版和程式碼高亮，方便閱讀
- 一鍵複製問題和答案
- 介面支援簡體中文、English、日本語、繁體中文，隨時切換
- 你的對話記錄和設定都儲存在本機瀏覽器裡
- Enter 傳送、Shift+Enter 換行

怎麼用：

1. 安裝後開啟 ClawTab 側邊欄。
2. 在設定裡填好你的模型位址、金鑰和模型名稱。
3. 開啟任意網頁。
4. 在輸入框裡問它目前網頁的內容，或者新建一個對話從頭聊起。

隱私說明：

ClawTab 本身不提供雲端 AI 服務，用的是你自己設定的模型。你輸入的內容、網頁文字和對話記錄只會傳送到你指定的模型介面。金鑰、設定、對話歷史和網頁內容預設都存在你自己的瀏覽器裡，不會上傳到任何第三方服務。
