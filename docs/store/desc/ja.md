ClawTab は、Chrome 拡張機能の環境で動作するブラウザ自動化アシスタントです。現在開いている Web ページからタイトル、URL、本文コンテンツを抽出し（Mozilla Readability + NodeHtmlMarkdown により markdown に変換）、サイドパネルで対話形式の質問応答体験を提供します。

Web ページの内容をすばやく理解したり、ページの詳細を質問したり、記事の要点を要約したり、現在のタブの内容をもとに設定した大規模言語モデルのインターフェースへ質問したりできます。マルチセッション機能により、複数の独立した会話コンテキストを並行して維持できます。

主な機能：

- Chrome サイドパネルでの Web コンテンツ質問応答
- 現在のタブのタイトル、URL、本文テキストを抽出し（Mozilla Readability + NodeHtmlMarkdown により markdown に変換）、URL 単位でスナップショットをキャッシュ
- OpenAI 互換の Chat Completions インターフェースに対応
- ストリーミング出力に対応し、モデルの思考プロセス（reasoning）の表示をサポート
- 組み込みのツール呼び出し：開いているタブの一覧と Web ページ本文スナップショットの取得、ツール呼び出し結果は markdown でレンダリング
- バックグラウンドでページを開いて内容を自動取得：モデルはフォーカスを切り替えずに URL を開いて本文を読み取り、すでに開いているページは再利用
- マルチサイト検索：総合検索（Google / Bing / Baidu）と商品検索（Taobao / JD / Goofish / Amazon / eBay / Best Buy）
- チャット内の引用ジャンプ：回答内で参照されたタブはクリック可能で、対象ページを直接開くかフォーカス
- マルチセッション管理：独立した会話の作成、切り替え、削除
- Markdown 回答のレンダリングとコードハイライトに対応
- 質問と回答のコピーに対応
- 多言語 UI：簡体字中国語、English、日本語、繁体字中国語、設定で切り替え可能
- チャットセッションとメッセージを IndexedDB に永続化、モデル設定を `chrome.storage.local` に保存
- Enter / Shift+Enter による送信と改行のショートカット

使い方：

1. 拡張機能をインストール後、ClawTab のサイドパネルを開きます。
2. 「大規模言語モデル設定」で Base URL、API Key、Model を入力します。
3. 任意の Web ページを開きます。
4. 入力欄で現在の Web ページ内容について質問するか、新しいセッションを作成して独立した会話を開始します。

データについて：

ClawTab は独自のクラウドモデルサービスを提供しません。ユーザーの入力、Web ページのテキスト、チャットコンテキストは、ユーザー自身が設定した大規模言語モデルのインターフェースへ送信されます。API Key、モデル設定、セッションとチャット履歴、および Web ページのスナップショットは、デフォルトでローカルのブラウザストレージ（`chrome.storage.local` + IndexedDB）に保存され、第三者のサービスにアップロードされることはありません。
