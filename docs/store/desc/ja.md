ClawTab は、Chrome のサイドパネルで動くスマートアシスタントです。今開いている Web ページを読み取り、内容の理解や質問への回答、要点のまとめを手伝ってくれます。まるでページを先に読んでくれた相棒がそばにいるような感覚です。

サイドパネルを開いて「この記事は何について？」と聞けば、目の前のページをもとに答えてくれます。調べもの、価格の比較、商品探しも頼めますし、複数の会話を同時に進めても内容が混ざりません。

主な機能：

- Chrome サイドパネルで、今見ている Web ページについていつでも質問・会話
- ページのタイトルと本文を自動で読み取り、見やすく整理して回答
- 回答を書きながら表示し、「考えている」過程も見られます
- 開いているタブの一覧表示やページ内容の読み取りを自分で行い、作業をこなします
- 見ているページを邪魔せず、バックグラウンドでそっとページを開いて読み取り
- マルチサイト検索：総合検索（Google / Bing / Baidu）と買い物の価格比較（Taobao / JD / Goofish / Amazon / eBay / Best Buy）
- 回答内で触れられたページはクリックでそのまま開けます
- いくつでも別々の会話を作成・切り替え・削除できます
- 回答は Markdown 表示とコードハイライトで読みやすく
- 質問も回答もワンクリックでコピー
- 表示言語は簡体字中国語、English、日本語、繁体字中国語。いつでも切り替え可能
- 会話の記録や設定は、すべてご自身のブラウザ内に保存
- Enter で送信、Shift+Enter で改行

使い方：

1. インストール後、ClawTab のサイドパネルを開きます。
2. 設定でモデルのアドレス、API キー、モデル名を入力します。
3. 任意の Web ページを開きます。
4. 入力欄で今見ているページについて質問するか、新しい会話を始めます。

プライバシーについて：

ClawTab 自体はクラウド AI を提供せず、ご自身で設定したモデルを使います。入力した内容、ページのテキスト、会話の記録は、あなたが指定したモデルにのみ送信されます。API キー、設定、会話履歴、ページの内容は、デフォルトでご自身のブラウザ内に保存され、第三者のサービスにアップロードされることはありません。
