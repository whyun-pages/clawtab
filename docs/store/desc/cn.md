ClawTab 是一个 Chrome 侧边栏智能助手。它能读懂你当前打开的网页，帮你理解内容、回答问题、总结重点——就像身边有个随时能聊网页的助手。

打开侧边栏，问一句「这篇文章讲了什么」，它就会结合当前网页给你答案。你也可以让它帮你查资料、比价格、找商品，或者同时开好几个对话，各聊各的互不干扰。

主要功能：

- 在 Chrome 侧边栏里就当前网页随时提问、聊天
- 自动读取当前网页的标题和正文，整理成清爽的文字后回答你的问题
- 边生成边显示答案，还能看到它「思考」的过程
- 它能自己列出你打开的标签页、读取网页内容，帮你完成任务
- 在后台悄悄打开网页并读取内容，不会打断你正在看的页面
- 多站点搜索：综合搜索（Google / Bing / 百度）和购物比价（淘宝 / 京东 / 闲鱼 / 亚马逊 / eBay / Best Buy）
- 回答里提到的网页可以直接点开，一键跳转
- 多个对话随意创建、切换、删除，互不影响
- 答案支持 Markdown 排版和代码高亮，方便阅读
- 一键复制问题和答案
- 界面支持简体中文、English、日本語、繁体中文，随时切换
- 你的对话记录和设置都保存在本地浏览器里
- Enter 发送、Shift+Enter 换行

怎么用：

1. 安装后打开 ClawTab 侧边栏。
2. 在设置里填好你的模型地址、密钥和模型名称。
3. 打开任意网页。
4. 在输入框里问它当前网页的内容，或者新建一个对话从头聊起。

隐私说明：

ClawTab 本身不提供云端 AI 服务，用的是你自己配置的模型。你输入的内容、网页文字和对话记录只会发送到你指定的模型接口。密钥、设置、对话历史和网页内容默认都存在你自己的浏览器里，不会上传到任何第三方服务。
